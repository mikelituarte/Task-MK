# Política de seguridad

## Cómo avisar de una vulnerabilidad

Los avisos de vulnerabilidades se envían **solo** mediante el *private vulnerability reporting* de GitHub:
pestaña **Security** del repositorio → **Report a vulnerability**.

**Nunca** abras un *issue* público, una *discussion* ni un *pull request* para informar de una vulnerabilidad,
ni la menciones en comentarios públicos. Así se evita revelarla antes de que exista una corrección.

## Qué incluir

- Descripción del problema y su impacto.
- Pasos para reproducirlo, o una prueba de concepto mínima.
- Versión, commit o ruta del código afectado.

No incluyas datos personales de terceros ni credenciales reales en el aviso.

## Alcance

Este repositorio es público. La seguridad de Task-MK no depende de que el código sea secreto, y el repositorio
no contiene secretos ni datos operativos (dominio real, servidores, cuentas o rutas de backups).
Si encuentras alguno, avísalo por el mismo canal privado.
